# Product Backlog base

Las épicas se dividirán en historias pequeñas antes de cada sprint. Prioridad inicial propuesta por valor y dependencia.

## HU01 Extracción de datos

Como analista de datos, quiero obtener información desde al menos una API abierta para disponer de una fuente reproducible para el análisis.

Prioridad: Alta. Criterio base: Respuesta validada, fuente documentada y errores de conexión registrados.

## HU02 Calidad y almacenamiento

Como analista de datos, quiero limpiar, transformar y almacenar los datos para entrenar modelos con información consistente.

Prioridad: Alta. Criterio base: Nulos y duplicados tratados, esquema validado y dataset procesado disponible.

## HU03 Comparación del procesamiento

Como responsable técnico, quiero comparar tres alternativas de procesamiento en Google Colab para seleccionar la más adecuada según tiempo, recursos y calidad.

Prioridad: Alta. Criterio base: Tres alternativas evaluadas sobre el mismo dataset y condiciones documentadas.

## HU04 Modelos de aprendizaje automático

Como científico de datos, quiero entrenar y comparar al menos tres modelos para seleccionar el que mejor resuelva el problema definido.

Prioridad: Alta. Criterio base: División de entrenamiento y prueba, métricas apropiadas y selección justificada sin fuga de datos.

## HU05 Dashboard y predicciones

Como usuario de negocio, quiero consultar predicciones y métricas en un dashboard para interpretar los resultados y apoyar decisiones.

Prioridad: Media. Criterio base: Visualizaciones legibles y resultados vinculados con el modelo seleccionado.

## HU06 Seguridad del pipeline

Como responsable de seguridad, quiero evaluar riesgos de APIs y servicios e implementar controles para preservar la confidencialidad, integridad y disponibilidad.

Prioridad: Alta. Criterio base: Matriz de riesgos, controles verificables y ausencia de credenciales en Git.

## HU07 Gestión y propuesta de valor

Como Product Owner, quiero revisar backlog, avance y propuesta de valor para priorizar el producto y comparar lo planificado con lo ejecutado.

Prioridad: Media. Criterio base: Sprints y responsables registrados; desviaciones y modelo de negocio documentados.
